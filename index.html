Restaurant ordering & delivery

Live Next.js 16

The whole path a customer and a kitchen actually walk: a bilingual menu with per-item options, a cart, checkout with zone-priced delivery, a live order tracker, and the board the staff works from behind the counter.

Based on a system I built for an independent restaurant.

  • English/Hebrew from the data layer up — the layout mirrors to RTL, and the two string dictionaries are checked for parity at compile time
  • Shabbat and yom-tov closures computed from the Hebrew calendar, not a hardcoded weekly table
  • Money summed as integer agorot by one function shared across cart, checkout and order record

LeadGraph — researcher lead intelligence

Live React · deck.gl

Life-science vendors sell to scientists, and which scientists are worth calling is written in the literature. LeadGraph turns publishing activity into ranked, explainable, geo-mapped sales leads — with a weight tuner that re-ranks the whole run live.

My own product; a ground-up rewrite of a 23k-line Excel/VBA tool.

  • Every score decomposes into five named components, so a rep can disagree with a driver rather than the whole ranking
  • Communities, betweenness and PageRank computed in the browser over whichever edge set is displayed
  • Four distinct empty states — still running, still computing, genuinely empty, filtered out — that a careless build would conflate

Yeshiva Operating System

Live Next.js 16

The back office of a school as one system: recruiting, donor and alumni pipelines on a single contact record, student records, giving history, tasks — and an approval queue where every action an AI agent proposes waits for a human to accept or reject it.

Based on a CRM I built for a yeshiva.

  • Agents propose, people decide: approving a stage move is the thing that moves the contact, and every decision appends to an audit trail
  • No confidence threshold above which an agent proceeds alone — the queue reports "auto-executed: 0" as a design fact, not a metric
  • Rejections capture a reason, because that is the signal the next agent run actually needs
